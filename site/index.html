Requires your own API key. This page makes no model calls. Confidence is a routing signal, not a correctness guarantee.

Python / jev-1.13.0 
pip install typesafe-sdk

Set TYPESAFE_API_KEY in your environment, then run:

from typesafe_sdk import Choice, TypeSafeClient

with TypeSafeClient() as client:
    result = client.system_one(
        model="jev-1.13.0",
        state="I was charged twice.",
        questions={
            "category": Choice(
                instructions="What is this ticket about?",
                criteria={
                    "billing": "Charges and refunds",
                    "technical": "Technical problems",
                    "other": "None of the above",
                },
            )
        },
    )

answer = result.choices["category"]
print(answer.choice, answer.confidence)
