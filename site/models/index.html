Comparison and license notes+

These releases come from independent publishers, not TypeSafe’s Jev weights. An alternative is a candidate for comparison, not a guarantee of equivalent behavior, accuracy or interface support. Check the official documentation separately for hosted Jev versions and capabilities. TypeSafe model documentation

Each entry keeps its publisher, model-card link and a short scope note. Do not infer a release’s license from its base model: code, adapters, merged weights and data can have different terms. Availability for download and permission for commercial use are different questions; consult the publisher’s materials. Models and licenses guide

This directory does not rank releases by scores that we have not evaluated under common conditions. Match candidate sets, modalities, label sources, reasoning budgets, hardware and evaluation splits. Keep public tests, publisher-run evaluations and private-inclusive boards separate. The notes describe inspected documentation, not model execution or reproduced results. Comparison conditions
